# Data

Download the [McDonald's Store Reviews dataset](https://www.kaggle.com/datasets/nelgiriyewithana/mcdonalds-store-reviews) and place the source file at:

```text
data/raw/mcdonalds_reviews.csv
```

The raw dataset is excluded from Git. The analysis uses 33,396 reviews and retains `reviewer_id`, `review`, and `rating` for sentiment and topic modelling.
